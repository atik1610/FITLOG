# 💪 FitLog — Workout Library

A dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## Technologies
Next.js (App Router) · React · Tailwind CSS v4 · lucide-react · Vercel

## Features
- Responsive workout library (3×4 grid on desktop) with live API data
- Sort by Duration, Calories or Rating
- Detail page with specs table, instructions and toast-backed actions
- My Plan with Today's Plan / Saved tabs, live Exercises/Minutes/Calories metrics
- Mark as Done and Remove, 5-lift daily cap, localStorage persistence
- Loading states, custom 404 page, API fallback endpoint

## Run
```bash
npm install
npm run dev
```
